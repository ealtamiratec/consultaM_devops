PASOS DE DESPLIEGUE RÁPIDO
================================================================================

1. CONFIGURAR DOCKER (3 minutos)
   - Abrir Docker Desktop
   - Settings > Docker Engine
   - Agregar: "insecure-registries": ["localhost:5000"]
   - Apply & Restart

2. DESPLEGAR (15 minutos)
   chmod +x deploy-all.sh
   ./deploy-all.sh

3. VERIFICAR (5 minutos)
   ./verify-deployment.sh

4. CONFIGURAR JENKINS (5 minutos)
   - Abrir http://localhost:8080
   - Crear nuevo Job Pipeline
   - Configurar SCM con repositorio Git
   - Asegurar Script Path: Jenkinsfile
   - Build Now

================================================================================
SOLUCIÓN DE PROBLEMAS
================================================================================

Problema: Docker Registry no disponible
Solución: Reiniciar Docker, verificar configuración de insecure-registries

Problema: Jenkins no responde
Solución: Ver logs con kubectl logs -n consulta-medica -l app=jenkins

Problema: Aplicación no conecta a MySQL
Solución: Verificar que MySQL está corriendo, revisar logs

Problema: Pods en estado Pending
Solución: Verificar recursos disponibles, revisar eventos

Para más ayuda: Ver TROUBLESHOOTING.md
